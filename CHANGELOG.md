# Changelog

All notable changes to the AuthFramework Python SDK will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-09-29

### Added
- Initial release of AuthFramework Python SDK
- Complete authentication and authorization client
- Support for login, logout, registration, password reset
- JWT token management and validation
- Role-based access control (RBAC)
- User profile management
- Admin operations for user and system management
- FastAPI integration middleware
- Flask integration middleware
- Comprehensive async/await support
- Full type hints and Pydantic validation
- High test coverage with pytest
- Complete API documentation
- Examples and integration guides

### Security
- All API communications use HTTPS by default
- Secure token handling and storage
- Input validation and sanitization
- Protection against common web vulnerabilities
